Local gradle settings
=====================

The first invocation of any task in Lucene's gradle build will generate
and save a project-local 'gradle.properties' file from a template,
with some default gradle JVM settings, which you can modify to your needs.

See your 'gradle.properties' file for more details of those settings.


Intranet mirrors for gradle (wrapper and distribution)
======================================================

gradlew downloads gradle-wrapper.jar (from GitHub) and the gradle
distribution (from services.gradle.org) on first use. If these hosts are
not reachable, point gradlew at internal mirrors with environment
variables (both are optional and may contain a ${gradleVersion}
placeholder, replaced with the version from gradle/wrapper/gradle-wrapper.properties):

LUCENE_GRADLE_WRAPPER_URL=https://mirror.example.com/gradle/${gradleVersion}/gradle-wrapper.jar
LUCENE_GRADLE_DISTRIBUTION_URL=https://mirror.example.com/gradle/gradle-${gradleVersion}-bin.zip

When either is set, gradlew runs IntranetGradleSetup.java first: it downloads
gradle-wrapper.jar into gradle/wrapper/ (the jar must match the checksum in
gradle-wrapper.jar.sha256) and installs the distribution (which must match
distributionSha256Sum in gradle-wrapper.properties) into the gradle user
home (GRADLE_USER_HOME or ~/.gradle) at the location the gradle wrapper expects
for the official distribution URL, so nothing else needs to be downloaded.
Local files work too, e.g. LUCENE_GRADLE_DISTRIBUTION_URL=file:///path/to/gradle-9.7.0-bin.zip

Setting LUCENE_GRADLE_VERIFY_CHECKSUMS=false disables checksum verification
in these bootstrap steps: gradlew skips the gradle-wrapper.jar checksum
check (and the automatic download of the jar if it is missing or does not
match gradle-wrapper.jar.sha256), and IntranetGradleSetup uses an existing
gradle-wrapper.jar as-is and installs what it downloads without verifying
it against gradle-wrapper.jar.sha256/distributionSha256Sum. Use this only
if you trust the origin of the jar and the mirror URLs.


Build options
=============

There are also various options that the Lucene build uses, which can affect
how tests are run or enable additional features (for example enable code
coverage or profiling).

To see the current values of all these options, run:

./gradlew allOptions

this prints all build options for all modules. You can print all options
for a single module too, for example:

./gradlew -p lucene/core buildOptions

The output of both tasks shows the options, their current values
and their current value's "source". All build option values can be
overridden by, in order of priority:

 * cli parameters to gradlew (system properties): -DoptionKey=value
 * cli parameters to gradlew (gradle properties): -PoptionKey=value
 * env variables: optionKey=value ./gradlew ...
 * property file (local for you, non-versioned!): build-options.local.properties
 * property file (versioned): build-options.properties

If you'd like to tweak some of the build options permanently, use the
build-options.local.properties file. For temporary overrides, use
cli parameters (preferably gradle parameters -Pxyz=value).
